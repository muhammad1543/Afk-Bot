# Skills

Skills are modular capabilities for the personal AI agent.

Each skill should have a `SKILL.md` describing:
1. What the skill does
2. Trigger phrases
3. Inputs and outputs
4. Tools/APIs required
5. Required permissions
6. Step-by-step workflow
7. Failure handling
8. Tests/examples
